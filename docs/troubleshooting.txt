TROUBLESHOOTING
===============

Start with 'bunqctl auth status' (connection, IPs, session) and rerun the
failing command with -v (method, path, status, response id). When asking bunq
support, quote the response id from the error.

Sweep
-----

  Output                                 Meaning
  -------------------------------------  -------------------------------------
  nothing to sweep                       Balance at or below --keep, or no
                                         income in the period

  period already swept by payment N      A previous sweep --percent run for
                                         these exact dates exists. Intended;
                                         change --percent or the dates for a
                                         new run

  use exactly one of --keep or           Pick one mode
  --percent

'sweep --percent' counts only money others paid you on the source account. If
income arrived on another account, pass --from for that account.

Output
------

  Symptom                                Fix
  -------------------------------------  -------------------------------------
  Table columns truncated                Descriptions are cut to fit; use
                                         --json for full text

  Dates look off by one day              Tables and --from/--to use your local
                                         time zone; JSON dates are RFC 3339 in
                                         UTC

  insights is empty or lacks recent      bunq indexes with a delay
  payments

  Sums in jq show 567.8199999999999      jq uses floating point; round at the
                                         end, e.g. (. * 100 | round) / 100
